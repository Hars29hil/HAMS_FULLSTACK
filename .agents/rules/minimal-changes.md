# Antigravity Rules: Minimal Code Changes

## Code Modification Protocol
- Find bugs/errors in the code without refactoring unrelated logic.
- Make the SMALLEST possible change required to resolve the bug.
- Do NOT modify unrelated code or lines.
- Do NOT add extra lines unless strictly required.
- If one line fixes the issue, change ONLY that one line.
- Do NOT refactor existing code unless explicitly requested.
- Do NOT add comments, documentation, logging, error handling, or abstractions unless strictly required for the requested task.
- Preserve the existing architecture and coding style.
- Before changing code, identify and explain the exact cause of the problem.
