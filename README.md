# Hostel Attendance Management System (HAMS)

A comprehensive, production-ready system to manage hostel attendance using ESP32 hardware, a Node.js backend, and a Flutter frontend.

## Architecture

The system consists of three completely separated modules:

1. **`frontend/`**: Flutter application for Admin and Student access (Mobile & Web).
2. **`backend/`**: Node.js + Express + TypeScript server handling business logic, REST APIs, and database interactions.
3. **`esp32-services/`**: ESP32 firmware for hardware interaction at each floor.

### Backend Validation

The backend acts as the single source of truth. It validates all attendance events generated by the ESP32 floor devices to prevent spoofing or out-of-bounds operations (e.g., student trying to mark attendance on the wrong floor, or after the session is closed).

## Setup Instructions

### 1. Database Setup (XAMPP / MySQL)

- Start Apache and MySQL in XAMPP.
- Run the provided schema script located in `docs/database/schema.sql`. You can import this via phpMyAdmin or MySQL CLI.

### 2. Backend Setup

```bash
cd backend
npm install
# Ensure you copy .env.example to .env and configure DATABASE_URL
npm run dev
```

### 3. Frontend Setup

```bash
cd frontend
flutter pub get
# Ensure you copy .env.example to .env
flutter run
```

### 4. ESP32 Setup

Refer to `esp32-services/README.md` (to be created in hardware implementation phase) for flashing the firmware. Update the configuration based on `esp32-services/.env.example`.

## API Integration Note

Student basic details will be synced/fetched using the external API:
`GET https://api.avdvvn.org/public/getStudentBasicDetails`

## Development Order

Refer to the internal project phases for systematic development. Do not mix frontend logic, backend routing, and hardware logic.
